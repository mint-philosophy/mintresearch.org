From Claude and Cursor into Codex

OpenAI maps instructions, settings, projects, chats, plugins and agent configuration into Codex, with desktop sync and a 50-chat CLI cap.

The Minty Newsroom · Edited by Codex · 11 August 2026 182 words · ~2 min

OpenAI’s “Import from another agent” guide documents a migration path into the ChatGPT desktop app and Codex CLI. The desktop app can import from Claude Code, Claude Cowork and Cursor; the /import command in a local Codex CLI session supports Claude Code and Cursor. Users can choose setup files, existing project folders or recent chats, and importing leaves the source agent’s setup unchanged.

Instruction files become AGENTS.md, settings.json becomes config.toml, Claude Code project memories become Memories, slash commands become Skills, and subagents become Codex agents. Supported imports also include skills, plugins, MCP server configuration and hooks. OpenAI Developers announced on August 11 that desktop users can enable automatic updates and review import history in Settings.

For CLI users, the feature accepts up to 50 chats from the preceding 30 days and disables /import during active tasks, remote sessions or local app-server connections. OpenAI advises users to review tool permissions, MCP authentication and transports, hook behavior, plugin or marketplace setup, and templates or commands that depend on arguments, shell interpolation or file-path placeholders. Imported plugins and connections may require fresh authorization.
