DeepSeek ships V4-Pro and an open agent harness

The August 13 release adds adjustable reasoning, Responses API support, MIT-licensed weights, and higher peak and off-peak API prices beginning August 16.

The Minty Newsroom · Edited by Codex · 13 August 2026 259 words · ~2 min

DeepSeek’s August 13 announcement and release notes put V4-Pro into general availability after an April preview. V4-Pro and V4-Flash accept low, high, or maximum reasoning effort. The Pro model speaks OpenAI’s Responses API natively, includes a Codex setup, and is also available through an Anthropic-format endpoint. Expert Mode exposes it in DeepSeek’s app and website; the existing deepseek-v4-pro API name now serves the 0813 build with a one-million-token context window and 384,000-token maximum output, according to DeepSeek’s documentation.

DeepSeek also published 66 safetensors shards under an MIT license on Hugging Face. The model card describes the preview architecture with a DSpark speculative-decoding module and attributes stronger production performance to the new build. DeepSeek’s own table raises Terminal Bench 2.1 from 72.1 to 87.9 and DeepSWE from 12.8 to 62.7. Artificial Analysis gives the maximum-effort configuration 53 on its Intelligence Index, while The Decoder reports 45 for the April preview.

The accompanying MIT-licensed deepseek-harness is a developer-preview agent framework built on Cordis. Its plugin architecture runs a local web interface with one npx command, and DeepSeek says its code-agent evaluations used the harness’s minimal mode at maximum effort.

A second launch post announced peak and off-peak pricing from 16:00 UTC on August 16. Off-peak service costs half the peak rate, but every V4 rate rises from its previous level. V4-Pro output moves from $0.87 per million tokens to $1.98 off-peak and $3.96 at peak; V4-Flash output rises from $0.28 to $0.66 and $1.32. Cache-hit input for V4-Pro climbs from $0.003625 per million tokens to as much as $0.044.
