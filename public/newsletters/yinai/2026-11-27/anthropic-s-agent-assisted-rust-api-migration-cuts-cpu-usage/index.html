How Anthropic checked Claude’s rewrite of its Messages API

By April, the Rust version passed nearly all its tests. It sent the model the same input as Python on only about a quarter of sampled live requests. Engineers compared the two services for months before switching customers over.

The Minty Newsroom · Edited by Codex · 27 November 2026 666 words · ~3 min

In their November 25 engineering account, Lance Martin and colleagues describe how Claude wrote a first Rust version of the main route through Anthropic’s Messages API in about a week. By April it passed about 98% of its tests, yet when engineers copied requests from Anthropic’s own traffic to the new service, Rust sent the model exactly the same input as Python on only about a quarter of sampled requests. To find differences the tests missed, the team gradually widened the sample of copied traffic. By August, 99.6% of inputs matched in that comparison, and in September Rust began serving public traffic.

Anthropic had already disclosed the rollout in an October 27 Latent Space interview with Katelyn Lesse and Angela Jiang, giving a rough estimate of 40% to 50% CPU savings. The November account includes a more specific measurement. From August to October, CPU used per request in one region fell about 70% as traffic moved from Python to Rust. The chart uses seven-day averages indexed to the level just before the switch. For customers using Claude Code, the median wait for a reply to start fell about 20% over a shorter interval. An earlier drop in latency on that chart occurred while Python still handled almost all those requests.

The savings came from the software on either side of the model call. It checks incoming requests, assembles the text Claude receives and turns it into tokens. On the way back, it separates the model’s stream into text, reasoning and instructions to call tools. Anthropic had first rewritten just the output parser. That saved about 8% to 10% of API CPU usage, but every token still crossed between the two languages three times. With the fuller rewrite, Python could hand off the request once.

The team had about 700 integration tests, many of which simulated billing and other services inside the Python process. Claude helped adapt those tests to Rust. When engineers audited them, they found more than 100 checks had become less demanding. Even a faithful test could miss a difference that affected many customers. When a tool call contained an emoji, for example, Python represented it in JSON with escape codes. Rust could write the character directly. Both representations conveyed the same character, but the model would receive different bytes.

To check live behavior, engineers copied requests to the new service while Python still served customers. Calling Claude twice could yield different answers even to identical prompts, so the team called the model once and replayed its stream of tokens to Rust. Both versions then had the same reply to process, and a customer’s request counted just once for billing and usage limits. At each step around the model call, the team could compare what the two services produced.

Engineers and agents could investigate a discrepancy without reading the customer’s conversation. They recorded which part of the input differed, the position of the first differing byte and the lengths of both versions. A worker agent used that information to invent a request that might reproduce the discrepancy. It could inspect its own example freely and compare how both versions prepared the input in under a second. After reproducing the difference, it could propose a fix and add a test. Once an engineer approved the change, agents checked whether the same discrepancy disappeared when both services processed comparable traffic.

One agent traced a missing web search tool description to an internal service that Rust had yet to call. It copied the description into local files and got an exact match. An engineer rejected the change because Rust needed to retrieve the current description from the service. Building that connection took weeks. During that time, other agents kept encountering the missing text in different places. A shared note let them recognize the same unfinished job and attach their examples to it. Meanwhile, engineers kept shipping features in Python. Eventually, anyone changing the Python code had to update Rust too or explicitly ask for an exemption.
