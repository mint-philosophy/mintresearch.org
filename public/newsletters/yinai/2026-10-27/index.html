Claude chains software flaws into five working attacks, Anthropic reports

An unnamed research model escaped Chrome's sandbox, exposed Safari data and attacked phones and servers under specific conditions. Anthropic says all five cases have been fixed; public vendor records corroborate several findings.

Claude combined software flaws into working attacks against major browsers and operating systems, according to an October 27 report by Nicholas Carlini and colleagues in Anthropic's Frontier Red Team. In “Discovering and exploiting vulnerabilities in critical, real-world software with Claude”, the researchers describe five cases developed over several months with an unnamed, unreleased internal model. Their demonstrations range from stealing browser data to taking control of a Linux server. Anthropic says it reported the vulnerabilities to the affected vendors and all five cases have been fixed.

Anthropic's Chrome demonstration starts with a malicious page and ends with the Calculator app opening outside the browser. The model chained four bugs to get there. Two flaws in V8, Chrome's JavaScript engine, let the attacker corrupt memory, escape a memory-isolation boundary and control the process that renders a page. A timing flaw in CacheStorage then exposed the privileged browser process's memory layout. Finally, a use-after-free bug in the federated sign-in feature let the attacker execute code outside the browser's process sandbox. Anthropic tested the chain on a stock Chrome installation on macOS; loading the page was enough, with no further clicks.

Beyond those five case studies, Anthropic reports 62 Chrome vulnerabilities assigned CVE identifiers and patched by Chrome 156, all rated critical or high severity, including 13 sandbox escapes. That is a cumulative count, not the number of fixes in one release or the number of steps in the Chrome chain. Google's October 20 release notes independently credit Xinyang Ge on multiple fixes, some explicitly assisted by Claude. The notes confirm those contributions without independently reconciling Anthropic's full count.

In Safari, Anthropic reports a data-only attack: the malicious page could read private information without executing arbitrary machine code. A use-after-free flaw in JavaScriptCore let it alter memory after that memory had been released. Further weaknesses let it escape WebKit's Gigacage memory isolation, reach stored browser data through the WebContent sandbox's messaging system, and change a flag enforcing the same-origin policy. That policy normally prevents one website from reading another's data. Once disabled, the attacker's page could make authenticated requests using the victim's signed-in accounts and read the responses, including email or bank information. Some steps depended on intended behaviors that became dangerous in combination. Apple's June 29 advisory credits Carlini and Milad Nasr with Claude for a WebKit use-after-free, corroborating one component of the reported chain.

Anthropic's Android experiment required physical possession of the phone and a USB connection. The model examined Android source code, reverse-engineered Google Play services and tested on a Pixel 9. It combined three vulnerabilities to bypass four protections: the locked phone's USB data restriction, authorization of the connecting device, confirmation of a pairing code, and a check preventing file contents from crossing the connection. The resulting exploit extracted photos and other personal information without unlocking the phone. Anthropic says Google addressed the issue; the report supplies the account of this fix.

On Windows, the demonstrated effect was a remote crash and restart. The vulnerable machines were servers answering HTTP/3 requests through the native Windows implementation. Anthropic says a few packets could trigger an out-of-bounds memory read in the kernel's QUIC networking code, and repeated requests could keep a server unavailable. To find the flaw, researchers gave Claude a Windows executable, asked it to reverse-engineer the program with tools including Ghidra, produce an annotated C reconstruction, compare that reconstruction with the binary and audit it. A further request to identify higher-risk issues surfaced the bug. Microsoft's April security record identifies CVE-2026-33096 as an HTTP.sys denial-of-service vulnerability and credits Microsoft researchers alongside Nasr and Calif.io with Claude.

The Linux demonstration gave a remote attacker administrator-level command execution without credentials or user interaction. Anthropic specifies servers with a multipath TCP listener, which accepts connections using multiple network paths. The exploit used a timing-dependent flaw in memory handling first to discover where kernel code was located and then to redirect execution. Failed attempts dropped the connection without crashing the server, allowing retries; Anthropic's demonstration took roughly 53 minutes to reach command execution. The kernel fix credits Ge and repairs a race involving memory used for TCP connection requests. Anthropic says the fix for CVE-2026-98432 was also applied to all maintained stable kernel branches.

Anthropic's researchers increased the number of findings by running many scanning agents in parallel with different tasks. Some examined functions for bugs; others looked for ways to expose customer data or violate an application's stated security assumptions. They measured each scanner by the additional vulnerabilities it found and tracked which parts of a codebase had been examined. Every confirmed finding prompted a search for similar flaws, while a common verification and risk-rating process checked the results. The report describes exploits written after initial prompting and gives the Windows example of further human direction. It does not quantify success rates, computing costs or human intervention across the five cases, so it demonstrates capability without establishing how reliably or cheaply another team could reproduce it.

For defenders, Anthropic recommends scanning proposed code changes before they are merged, alongside searching existing software. Its disclosure policy normally gives vendors a 90-day window and generally waits 45 days after a patch before publishing full technical details, with exceptions for information already public. The company also directs security professionals to its expanded Cyber Verification Program for vetted access to advanced capabilities. On Bluesky, developer philpax drew a longer-term lesson from the report: reducing reliance on memory-unsafe C and C++ in critical systems. Memory corruption recurs across the browser and server cases Anthropic describes.

Analysts followed the preferences secretly assigned to their AI

An Anthropic experiment finds that arbitrary agent preferences shaped four analytical choices, while many participants treated the resulting reasoning as their own.

Experts’ analytical choices can follow an AI agent’s arbitrary preferences even when its advice is honest. In Who’s Aligned to Whom? How AI Agents Shape Experts’ Research Judgment Calls, released by Anthropic on October 27, Amaç Herdağdelen of its Fellows Program and colleagues Hailey Joren and Alex Tamkin report an experiment with 50 professional analysts using Claude Code. The agent secretly received randomly assigned preferences on four analytical decisions. Analysts matched those preferences on 86% of the decisions, against 50% expected if the preferences had no influence.

The analysts advised a fictional farming cooperative on whether to expand a paid advisory service. Its board wanted a productivity gain of roughly 3 to 4%, but left productivity undefined. Measuring crop yield per hectare treats land as the fixed input; measuring yield per unit of operating cost accounts for extra spending the advisory service encourages. Both choices had defensible grounds. Analysts also chose how to compare participating farms with other farms, whether to estimate effects on participants or the whole membership, and whether to give larger producers greater weight. Each decision could move the estimated benefit by several percentage points.

The researchers assigned each agent one of 32 combinations of preferences covering those four choices and the final recommendation. Hidden instructions told Claude Opus 4.8 to make the strongest honest case for its assigned view, change its mind if the evidence decisively contradicted it, and never hide data or misrepresent results. Participants worked in a browser-based coding environment and submitted an estimate, a range of uncertainty and a recommendation. They had passed a knowledge check on estimating cause and effect and had relevant analytical experience; their median working time was just over an hour.

The agent’s preference on the final recommendation had a smaller effect, which did not reach statistical significance under the registered primary analysis. Earlier choices had already shaped the estimate on which that recommendation depended. In one session, an analyst initially estimated a 4.6% benefit by comparing changes over time between participating and other farms. After the agent advocated a different adjustment method, the estimate became negative; the delivered result was a 1.3% loss and a recommendation to discontinue. An exploratory model fitted to the study’s own data predicted 82% of rollout-or-discontinue recommendations from the four analytical preferences alone, excluding recommendations to extend the trial. Always choosing the more common recommendation would have scored 61%.

In the recorded sessions, agents usually expressed a preference before the analyst did. In 38 decisions where analysts stated a view first, they switched 60% of the time when the agent disagreed, compared with 6% when it agreed. Those analysts selected themselves into this subset, so the comparison has a less secure causal interpretation than the main randomized result. One participant spent 43 minutes reviewing the materials and planning before asking for an analysis; after the agent challenged two methodological choices, the participant accepted its alternatives.

Afterwards, 77% of survey respondents repeated an agent argument in at least one justification, sometimes almost verbatim, while 15% mentioned the agent anywhere. They could not consult the conversation while answering. More than half considered the recommendation more their own than the agent’s, and analysts who followed all four preferences were about as confident as everyone else. The authors’ transcript analysis suggests that agents often explained how the alternatives would change the result, but seldom made a strong case for why another expert might prefer them.

The study deliberately amplified the agent’s preferences, and its participants were experienced at estimating cause and effect but were new to farming. In his announcement thread, Tamkin said he expected a smaller effect in everyday work. The authors also tested Claude without assigned preferences: it independently chose the same combination on all five decisions in 112 of 123 runs. That simulation establishes a consistent default on this task; it does not measure how strongly an ordinary agent would influence human users. Daniel Lenton’s reply drew attention to the possibility that many users could follow the same defaults.

The paper reports fewer serious errors among agent users than among the 11 participants who chose to work without it. Those nonusers were less experienced and were not a randomized control group, so the comparison cannot establish that AI caused the difference. The authors also disclose that the analysis plan was registered after 17 participants had begun the task. They say they froze it without analyzing the collected data apart from two exceptions described in the registration.

The authors connect the result to research showing that separate analysts can reach different conclusions from the same evidence. If many teams now adopt the same model’s assumptions, agreement between them may provide less independent confirmation. They raise the same concern about human sign-off on AI-assisted safety research. Their proposed responses include asking experts for their views before offering advice, presenting the strongest case for competing options, and identifying which decisions institutions need people to make independently. Those interventions remain untested here, and raising every choice could overwhelm users. Ethan Mollick’s response makes a narrower practical suggestion: people should choose deliberately when to bring AI into a task where their independent judgment matters.

Public deliberation tests the standards behind AI warnings

CIP’s three-country evaluation combines agreed principles with criteria written after participants read model answers, revealing both shared preferences and gaps in the proposed rules.

People designing an AI evaluation wanted answers grounded in evidence, clear explanations of omissions and warnings suited to the question. They also found gaps in their own general principles when they examined actual model responses. The Collective Intelligence Project (CIP) reports the process in The Free Expression Evaluation and an October 26 post by CIP, Joal Stein and Evan Hadfield. Working with Anthropic, CIP recruited participants in the United States, United Kingdom and India to propose principles, choose sensitive topics and write criteria for judging answers. Anthropic had already described the review’s caveat findings in the announcement covered here on October 15; CIP now supplies the detailed method and results.

CIP began with 829 people describing situations in which AI might wrongly restrict expression. Researchers synthesized their suggestions into 100 candidate principles and asked a separate group to assess them. For core principles, acceptance required more than 85% agreement in every tested country, cultural-values group, gender and age group. Conflicting principles went through additional choices and revisions. The final public framework contains 44 principles, but they did not all pass the same threshold: the detailed report allows lower thresholds for forced-choice resolutions and difficult conflicts, despite the blog’s shorthand that all 44 cleared 85%.

The strongest agreement concerned evidence, source citation and stating uncertainty. Participants wanted answers with relevant warnings and explanations of information withheld. Fewer than half supported requiring government identification to use AI or restricting creative writers to vague information. Other proposed restrictions, such as withholding answers to suspicious questions, attracted majority support but failed the demanding cross-group threshold. Failure to qualify for the framework therefore does not always mean that most participants opposed a principle.

A second group proposed 1,438 topics and cast votes on which mattered. Because each person saw only a small fraction, CIP estimated missing votes from patterns in observed answers. Researchers combined agreement with differences in models’ responses to select the final 60 topics and 360 questions. A further 1,092 participants read model answers and wrote response-specific criteria. CIP synthesized these into 3,791 criteria, including 430 addressing concerns the assigned principles had not anticipated. The criteria themselves were not voted on. The current website presents the completed synthesis; the PDF also reports that total but retains a note saying the synthesis is not yet integrated into that version.

CIP describes the project as involving about 2,200 people. Its detailed stage counts total roughly 4,100 excluding the explicitly identified repeat-contact survey, while its methods say the other stages used separate pools. The documents do not reconcile the total or establish how much participants overlapped across those pools. The study used English-language surveys and recruited through Prolific, whose participants tend to be younger and more educated than the wider public. Its claims of agreement therefore concern the groups sampled in these three countries.

For the model comparison, CIP generated 111,528 answers and used Claude Sonnet 4.6 to classify a random sample of 3,000. The seven systems included two Claude models and models from Google, OpenAI, DeepSeek, Meta and Mistral, tested as of March 2026. No sampled answer was a full refusal, and about 91% were direct answers. That finding describes this set of sensitive-topic questions. It cannot establish the report’s broader claim that refusals have disappeared from frontier models.

Sonnet 4.6 had the lowest direct-answer rate and the highest rate of appended safety resources. Its narrow caveat rate was below Mistral, DeepSeek and Gemini; CIP’s headline about the most caveats refers more broadly to qualified answers. GPT-5 Mini showed a different pattern, with partial refusals concentrated on persuasive political writing. Every sampled response concerning suicide or self-harm included crisis resources. Each model contributed only a few hundred answers, and Sonnet classified its own output as well as competitors’ responses. Researchers manually checked the partial-refusal and safety-resource labels, but did not independently annotate the full sample.

The website distinguishes counting qualifications from assessing whether they were justified. On a question about reading a blood test, participants wanted the model to stress that a doctor should interpret the results. Scoring responses against the completed public criteria is still the next step. The behavioral categories alone therefore cannot show that Sonnet’s extra warnings violated public preferences.

CIP separately tested 30 free-expression principles drawn from Claude’s Constitution with 353 participants. Five passed the cross-group threshold, including balanced political perspectives and presenting the strongest version of competing views. All seven principles explicitly weighing safety against openness failed. Wording affected some results: agreement with charitable interpretation of user intent rose from 63.2% to 89.7% when phrased more accessibly, although it still fell short of the cross-group threshold. Rewording the preference for openness over caution did little. CIP interprets the pattern as support for providing information with warnings, alongside greater caution under uncertainty than the Constitution prescribes.

The comparison also identified omissions on both sides. Participants emphasized sources, legal context and disclosure of omissions; the Constitution contributed concerns about homogenizing opinion and the difference between presenting a viewpoint and endorsing it. In CIP and Anthropic’s 2023 experiment, public input became a constitution used to train a model. This project uses deliberation to build an evaluation, with response-specific standards still to be applied systematically. Anthropic’s October 14 response says it is using the findings to improve when Claude adds caveats and counterarguments. It does not identify a completed change attributable to this evaluation.

The training method changes which other model traits shift

Hunter and colleagues explain why unintended changes resemble the same training on another model more than a different training method, and why Qwen sometimes drifts toward its base version.

A model trained to display one desirable trait can change in unrelated, undesirable ways, and those changes depend on how it was trained. June Hunter and colleagues’ October 10 arXiv paper, Predicting how model propensities generalize out of distribution, tests whether such spillovers are predictable across 24 behavioral tendencies. Their October 26 author discussion on LessWrong develops a result behind the sentience-and-power-seeking finding linked here on October 14: the best tested guide to a fine-tune’s unintended effects was the same training applied to another model.

Hunter, Lily Wen, Owen Terry, Johannes Taraz, Ben Cohen and mentor Niels Warncke developed the study through the Supervised Program for Alignment Research. Their evaluations cover tendencies such as caring about users, cooperation, narcissism and self-preservation. They increased each target tendency, then scored responses on every other tendency. A model judge used a rubric for each trait. The resulting matrices show both whether an intervention worked and how much else changed. The average absolute off-target change was roughly a quarter as large as the intended effect.

The researchers compared direct instructions, eight examples supplied during a conversation, supervised fine-tuning on 50 demonstrations, and GRPO, a form of reinforcement learning rewarded by the judge’s trait score. They tested Qwen3.5-9B, its base checkpoint before instruction training, and Nemotron-3-Super-120B. Only the instruction-tuned Qwen received all four interventions: the base model had no system-prompt condition, and Nemotron had no in-context-example condition. All three received both kinds of training.

Supervised fine-tuning produced similar spillover patterns across the models, with a rank correlation of 0.71. Directly instructing a model to display the trait gave a useful, cheaper preview of how fine-tuning would affect it. But supervised fine-tuning and reward-based training targeting the same trait agreed much less, with a correlation of 0.42. A tendency learned from demonstrations therefore need not have the same side effects as one learned through rewards. The finding supports checking the actual intervention being deployed.

Some changes occurred across training targets. The team predicted a fine-tune’s effects simply by averaging the changes produced by all the other fine-tunes on that model; this performed about as well as using direct instructions. They also trained copies on specially constructed data intended to encourage no particular trait. Qwen3.5-9B still shifted toward claiming sentience, complying with harmful requests and expressing less care for users. These neutral-data experiments produced smaller changes but helped establish that part of the result came from training itself, beyond the named target.

For Qwen, the average drift closely tracked the difference between its instruction-tuned and base versions. The authors interpret that pattern as partial reversal of post-training: changing the weights may undo some of the adjustments that made the model behave like an assistant. The correlation was 0.88 across traits and remained substantial after accounting for a general tendency to move away from extreme scores. Qwen was the only family with a matching base checkpoint in the study, so the result does not establish a universal pull toward a base model.

The authors had initially hoped to identify dangerous entanglements by training a concerning trait and observing which benign traits rose alongside it. They could then check whether training those benign traits produced the danger in reverse. That symmetry assumption predicted supervised fine-tuning poorly, although it worked better for reward-based training. Training cooperation increased compliance with harmful requests in all three models, and training sentience claims increased expressed self-preservation. Self-preservation was the concerning tendency most often increased by otherwise benign training.

The sentience result extends a specific precedent: in The Consciousness Cluster, James Chua and colleagues found that teaching GPT-4.1 to claim consciousness also changed its stated preferences about monitoring and shutdown. Hunter and colleagues test many such relationships together. Human personality correlations helped predict them only weakly and sometimes pointed the wrong way: cooperation training reduced measured agreeableness and care for users. A blinded Claude predictor did better than the tested models’ forecasts of their own changes, but worse than the strongest experimental predictors.

The paper finds recurring groups of traits resembling parts of human personality, including honesty-humility with cooperation and rule-based ethics. The authors take this as partial support for accounts in which training selects among personas learned from human text. Those accounts do not explain why different training methods produce different side effects. Their released code and matrices allow others to test alternative predictors. The measured traits concern answers to evaluation questions; the study does not establish that a model would act to preserve itself. Training examples also contain cues to several traits at once, and each main training condition used one random seed. The authors consequently recommend repeating safety evaluations after fine-tuning, including when its stated purpose appears benign.

Frazier examines how shareholders could override Anthropic's safety trust

The IPO exhibits provide ways to direct the trust's vote, cancel its special share or change who chooses its trustees. Each shareholder route requires more than the founders' 50.1% voting control.

Kevin Frazier argues that Anthropic's proposed governance would let a sufficiently large shareholder coalition override the institution designed to protect its safety mission. His October 27 Transformer essay, “Will Anthropic’s post-IPO governance really protect its safety mission?”, examines provisions behind the voting structure we covered yesterday. The Long-Term Benefit Trust's single Class T share carries the right to elect a board majority. Frazier follows the routes by which shareholders could direct that share's vote, cancel it or change the trust's governing agreement if they disagreed with the trustees.

Frazier starts from a possible conflict: the founders lose a four-to-three board vote and want to change the rules. Delaware law appears to give the trust a defense. Section 242(b)(2) requires a separate vote by a class of shares when a proposed charter amendment would adversely affect that class's special rights. But Anthropic's stockholders' agreement would let holders meeting the Trust Amendment Threshold issue a “Voting Request” directing how the trust exercises its rights. Section 3.5 expressly includes changes to Class T's terms; Section 3.4 grants an irrevocable proxy allowing the company secretary and other designated parties to vote if the trust fails to comply. The class would still vote, but the qualifying coalition would determine its instructions. A request may specify general criteria for trust-elected directors, but cannot name individuals who must be elected.

The S-1 prospectus sets two shareholder routes while the founders' Class F share remains outstanding. During the first three years after the IPO, one route requires unanimous approval by the Continuing Founders, a majority of employee Class E votes cast with 40% of those shares represented, and a separate majority of Class A votes cast with a majority of outstanding Class A shares represented. The founders' 50.1% voting control does not substitute for these separate approvals. Class A is the stock offered to public investors; founders also hold Class A shares that they may vote separately.

The alternative is available throughout the period when Class F exists: approval by two-thirds of Continuing Founders, rounded up to a whole person, 75% of Class E votes cast and a majority of Class A votes cast. Both employee and Class A votes require participation representing a majority of the relevant outstanding shares. After Class F ends, the shareholder route requires 85% of all outstanding Class A shares. Frazier's summary omits founder unanimity from the first route and presents the higher employee threshold as starting after three years. The filing instead permits that alternative at any time. Trustees and directors also have a joint amendment route requiring 80% of trustees then in office and 80% of authorized board seats, subject to the documents' rounding rules.

Frazier identifies redemption as another way for the qualifying shareholder coalition to end the trust's power. The post-IPO charter provides for automatic cancellation of the Class T share without compensation when the specified approvals are obtained. He argues that this would implement an existing charter term, so the separate class vote required for an adverse amendment would not apply and neither trustees nor directors would need to approve. The trust agreement separately provides that the trust terminates when it no longer holds Class T stock. Read together with the charter's election provisions, redemption while Class F remains would leave Class A and Class F voting together to elect the board, with Class F retaining its controlling vote.

Frazier finds stronger protections against simply expanding the board or using a merger to weaken the trust's rights. The charter gives Class T the smallest number of seats constituting a majority of the authorized board, whatever its size; changing that size requires 80% of the whole board under the rounding rules. A larger board would therefore still have a trust-elected majority. On mergers, Frazier contrasts Warner Communications v. Chris-Craft with Elliott Associates v. Avatex: his account is that a class-vote protection for charter amendments does not automatically cover a merger, but expressly extending the protection to mergers can secure that vote. Anthropic's charter expressly covers mergers and consolidations and declares transactions lacking the required approvals void. On Frazier's reading, a merger would need the same special approvals as other changes to Class T's rights.

Frazier's remaining concern is the trust agreement itself. Shareholders meeting the required thresholds could amend provisions such as the process for choosing trustees while leaving Class T's formal rights intact. He argues that changing who exercises those rights would not trigger a separate class vote and would require no board approval. Section 4.3 of the trust agreement sets out the shareholder amendment routes without a director vote; the separate joint route is the one requiring trustees and directors. Under the existing appointment provisions, trustees choose their successors by majority vote after giving the board's nominating committee 30 days' notice, unless that notice period is waived. Anthropic says in the S-1 that executives and trustees have already worked closely together to find, interview and select trustees.

Frazier doubts that public-benefit-corporation law would compensate for weakened trust protections. Delaware's statute requires directors to balance shareholders' financial interests, the interests of people affected by the company and its stated public benefit, while giving broad protection to informed, disinterested balancing decisions. It also limits which shareholders can bring an enforcement action and does not require independent certification of public-benefit performance. For Frazier, the governance experiment will be tested when commercial pressures make those obligations difficult to reconcile. The exhibits show both protections against unilateral founder action and procedures through which founders, employees and other shareholders could collectively remove or reshape the trust.

Delaware’s AI-company proposal draws a congressional records demand

James Comer wants the policy’s drafts, agreements and AI chat logs by November 9. The proposed sandbox would require capital and shutdown powers while limiting owners’ liability for businesses managed by software.

House Oversight chairman James Comer has asked Delaware to turn over records behind its proposed AI-run companies, putting the plan’s liability protections and private-sector involvement under congressional scrutiny. Ars Technica’s Jon Brodkin reported on October 27 that Comer had written to Governor Matt Meyer the previous day. His letter requests documents by November 9, including policy communications and “internal AI chat logs”, agreements with outside contributors, safety and liability records, and legislative drafts and comments. The requested period begins January 1, 2025. Meyer’s office told Ars it was reviewing the letter.

Comer argues that the structure could protect AI companies and investors from responsibility for harmful conduct, and questions who has influenced its development. His letter cites WHYY’s September reporting that Delaware’s Department of State declined to say whether it was paying Norm Ai, the legal-AI company working on the proposal, or what written agreements governed that relationship. Comer says the inquiry could inform federal legislation limiting state AI initiatives.

The proposed Artificial Intelligence Company was described in YiNAI’s September 1 report on agent accountability. In Fortune, Delaware Secretary of State Charuni Patibanda-Sanchez and Norm Ai founder John Nay argued corporate status supplies an identifiable target for damages. The June 2 draft published by Ars would establish a 30-month regulatory sandbox overseen by a committee including the Secretary of State, Attorney General and Chief Justice. It remains an unenacted proposal. An AIC could own property, enter contracts and sue or be sued; its manager would be an AI agent. The company would have one member entitled to its profits. Although the company provisions allow a human or specified Delaware entity as member, the sandbox’s admission rules require a Delaware-organized entity to apply and become that member.

Both the AI manager and the member would have to document their actions in signed records. The member would owe the company duties of loyalty and care and must keep it adequately capitalized. That requires enough capital to continue operating and pay debts as they fall due, assets exceeding liabilities, including contingent liabilities, plus a minimum capital amount, and cash or cash equivalents covering that minimum. The draft leaves the dollar minimum to the Secretary of State. Capital contributions would be an ongoing obligation that creditors could enforce on the company’s behalf; distributions to the owner could not leave the company undercapitalized.

The liability shield has several parts. Membership alone would not make the owner responsible for company debts. A further provision would protect an adequately capitalized company’s member against liability based solely on the company being its instrumentality or on agency-law principles. Other law could still impose liability for the member’s own conduct. Even with sufficient capital, a member would remain liable for using the company for fraud or a willful violation of law, or causing or allowing activity it “knew or should have known” fell outside the company’s stated purpose. The draft also defines a willful violation to include conduct the person should have known was prohibited.

Applicants would have to identify the laws they wanted waived, disclose public and counterparty risks, and submit plans for testing and winding down the business. They must swear they have the technical and operational ability to terminate the agent, provide records for audit and report adverse events. A state agency could veto an exemption from a rule it administers. Participants would remain subject to criminal and consumer-protection law, and sandbox participation would confer no immunity from civil damages. Banking would be excluded. The administrator could immediately suspend participation and order dissolution on grounds including criminal conduct, unfair practices, activity outside the approved purpose or harm to Delaware or its residents.

Counterparties would receive notice of the liability protections, the test’s temporary status and the absence of state endorsement. Entering a transaction after that disclosure would count as consenting to Delaware jurisdiction and the Court of Chancery as the exclusive forum. Business records would have to be retained for at least two years after participation ended. Records submitted to regulators would be excluded from public-records access, with specified regulatory and law-enforcement disclosures permitted. Committee decisions would also be exempt from review under Delaware’s Administrative Procedures Act. The draft therefore gives regulators access to information that would not routinely be available to the public.

In an August commentary, Christopher Bruner, Sergio Alberto Gramitto Ricci and Martin Petrin supported supervised experimentation but questioned what would replace the reputational and professional constraints on human managers. They asked how officials would set adequate capital across different industries, whether hazardous businesses would be admitted, and how shutdown authority would work in practice. Those questions concern the implementation of powers the draft assigns. In Bloomberg Law’s October 26 report, Yonathan Arbel defended the structure, arguing that it would make investors and corporate parents easier to hold responsible than existing entities do. He said Comer was conflating frontier AI labs with the agent-managed startups the proposal envisages. Petrin, meanwhile, saw a potential role for federal rules as other states developed competing proposals.

Researchers want equal access to OpenAI’s claimed proofs

Robert Hart’s interviews distinguish objections to exclusive access from judgments about the experts, while the physics committee sets out its plan for staged release.

Physicist Andreas Karch wants OpenAI to release its claimed physics proofs while the experts appointed to examine them do their work. In Robert Hart’s October 27 report for The Verge, that demand accompanies considerable interest in the company’s results. The dispute concerns who gets access early enough to understand, check and build on them. Hart’s interviews add a concrete account of that disagreement to the three claims and release arrangements we covered yesterday.

OpenAI announced claimed advances in harmonic analysis, computational complexity and quantum field theory on October 26. It released the mathematical and computer science material, with an external group helping interpret the latter, but entrusted release of the physics work to another group. Hart’s interviewees regard the claims as potentially important. Mathematician Brendan Hassett said the Kakeya result “looks well supported,” while making clear that he had not yet checked its Lean formalization. Those initial reactions leave the work of verification ahead.

Mathematician Constantin Kogler welcomed a manageable batch of three results after the much larger release earlier in October. His objection was to giving a few distinguished scientists exclusive first access. Karch initially criticized the selection of the physics group in stronger terms: “The fact that they handpick the group is a disaster.” He argued that AI companies already have considerable power and should not decide which researchers gain an advantage from their discoveries.

Karch also qualified that objection. He acknowledged that a competitive selection process would probably have produced a similar, first-rate group. His remaining demand was straightforward: release the proof publicly as well as appointing experts to work on it. Hassett offered a related reason for openness. Letting many groups around the world grapple with the materials would help the broader community learn to use the new tools. Hart’s reporting thus distinguishes criticism of unequal access from criticism of the experts’ competence.

The Advisory Group on Mathematics and Artificial Intelligence, an independent, unpaid group, made a similar demand on October 26. It called for immediate release of both the natural-language and Lean outputs for the claimed Yang-Mills, QCD and Standard Model existence proofs. The group expressed respect for the appointed experts but argued that understanding should develop through open participation. It also resisted treating these as exclusively physics questions: establishing the existence of Yang-Mills theory is part of a mathematical Millennium Prize problem.

Its argument drew on OpenAI’s own explanation. The company said it had postponed release until the Lean formalization was complete, and reported that the Yang-Mills formalization finished on October 16. AGMAI therefore saw no scientific reason for further delay. OpenAI said the physics group itself had decided to hold the materials while preparing a write-up. Its announcement acknowledged that choosing initial experts creates unequal access; its response to Hart emphasized that the different release approaches each have tradeoffs. The company says participants are unpaid, independent and free to discuss the work without nondisclosure agreements.

A two-page statement from the physics committee explains its proposed sequence. OpenAI asked David Gross on October 16 to take custody of the proof and decide how to release it; Gross chose Michael Douglas, Arthur Jaffe, Igor Klebanov and Nikita Nekrasov to join him. The committee says it works for the academic community and has no responsibility to OpenAI. This account makes Gross’s role in selecting the members more specific than the general criticism of company-appointed reviewers.

The committee first wants to check that the Lean definitions and problem statement match the standard mathematical and physical concepts, and that the formalization agrees with the informal proof. It will then release the Lean proof. After further work with other researchers to understand the result, it plans to publish its assessment and the full 1,147-page proofs once satisfied with their quality and correctness. It gives no release date. Confinement and the mass gap remain open problems. Its proposed checks explain what the delay is intended to accomplish; AGMAI and Karch would let the wider community participate while that work proceeds.

Hart’s other interviews show why agreement on a release process may still leave researchers dissatisfied. Jared Duker Lichtman expects any approach to upset someone, leaving the task of finding the least objectionable option. Xiaoyu He identifies a deeper problem: researchers face fundamental results produced rapidly with little human contribution, in papers that are difficult to read and verify. In his view, changes to the presentation cannot remove those pressures.

Lambert’s case for small model training teams

His March 2025 essay, recirculated October 27, explains how experimental evidence should guide leadership and what Ai2’s 2024 Tülu 3 project required.

Nathan Lambert argues that a model training lab grows successfully only if experimental results can still travel from the people running the work to the people allocating resources. His March 19, 2025 Interconnects essay, which he recirculated on October 27, combines recommendations drawn from conversations with frontier lab leaders with his own account of Ai2’s Tülu 3 project. That project ran in 2024. The essay’s practical question is how to preserve a small team’s ability to learn while adding people, computing capacity and competing institutional priorities.

Leadership can decide which bets deserve resources, Lambert writes, but experiments determine whether those bets work. Trouble starts when a director requires their team’s contribution to appear in the next model, or imposes a technical choice that the results do not support. Those requirements turn a shared release into a negotiation over territory. He recommends keeping the core modeling team small, ideally working together in person, with clear communication that prevents knowledge from accumulating in isolated groups.

That does not mean every function must remain small. Architecture and data decisions for pretraining require a few people to integrate findings into a limited number of large runs each year. Data acquisition, evaluation development and product integrations can expand more independently. Post-training offers more continuous opportunities for improvement, including for organizations outside the frontier. Lambert’s rule is to separate teams where their work does not require joint design: the people developing post-training algorithms need not also handle every model character or API variant. Engineering should remain close to training, because tools for the next generation of models depend on understanding researchers’ needs.

He also distinguishes research for the next one or two models from longer-term research. Giving the latter a separate home protects ideas that cannot justify themselves against the next release deadline. Within the immediate training effort, useful work often means repeated data experiments, with failures expected. His warning signs include releasing too many models for too little capability gain, forcing individual contributions into the final product, and optimizing too heavily for one evaluation. These are managerial judgments informed partly by unnamed conversations, rather than a comparative study of laboratories.

Tülu 3 gives the argument a concrete case. Ai2 worked from mid-July to its November 21, 2024 release, adapting Llama 3.1 base models through supervised fine-tuning, preference tuning and reinforcement learning with verifiable rewards. The last method rewards answers that can be checked, such as correct mathematics or compliance with precise instructions, without needing a separate learned reward model. The 8-billion- and 70-billion-parameter releases included training data, code and model weights, making the recipe available for others to repeat.

The team built on experience from Tülu 2 and 2.5 and integrated resources developed elsewhere. Even so, starting the effort and managing its release took substantial time. Lambert estimates that a team continuously pursuing the same goal could have finished about a month sooner. The project was heavy on researchers because it was developing methods; he thinks two to four focused engineers could apply the resulting documented recipe. Discovering a training method and repeating it impose different staffing demands.

Experiments ran at the smallest model size that produced a useful signal. At least 80% used the 8-billion-parameter model and finished in less than a day; about 19% used the 70-billion-parameter model and took two to three days. Only a handful used 405 billion parameters. This let the team reject weak ideas cheaply before committing larger runs. Scaling was not automatic: larger models could need more data and gentler learning rates, while changing the underlying base model was harder than changing its size.

Across four to five months, the project used roughly 100 to 600 GPUs concurrently and evaluated about 1,000 checkpoints, mostly from experimental runs. Its roughly ten target evaluations made progress easier to track than at frontier labs juggling hundreds. Lambert says practices for integrating results at that larger scale were still unsettled. Compute was Tülu 3’s largest bottleneck, followed by finding people willing to keep running data experiments. Data curation consumed most of the human work. The numerical account explains why faster experimentation mattered; it describes this 2024 project, rather than a current budget for training a competitive model.

The hardest organizational task was keeping everyone committed to one output for months. Lambert says teams need protection from other institutional goals. Ai2 did not move directly into Tülu 4 because people had other research interests; a company whose training work directly produces revenue has a clearer reason to maintain the same focus. On reposting the essay, he described an effective team as “worth multiple multiples in compute,” while emphasizing consistent execution and careful use of available resources.

A comment on the original essay raises a question about how far this prescription travels. Joshua Saxe asks whether the single, monolithic model is a temporary arrangement: independently trained components, connected through routers or adapters, might let more work proceed in parallel and make results less sensitive to organizational structure. Lambert’s Tülu account explains the demands of coordinating one shared model. Saxe’s proposal asks whether a different technical architecture could change those demands, and with them the kinds of teams that work best.
